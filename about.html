ABOUT THIS PROJECT

Good things find their way back.

Capitol Campus Lost & Found is a student project that helps the university community share lost and found item reports in one place.

How it works

  1. Post a lost or found item with its description, date, and location.
  2. Browse and filter reports, then add a comment to share useful information.
  3. Save the creator code shown after posting. The original poster uses it to mark the item claimed.
